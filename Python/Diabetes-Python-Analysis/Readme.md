## Project Title
Healthcare Diabetes Risk Analysis Using Python (Pandas)

## Business Problem
A healthcare facility wants to understand the factors associated
with diabetes and identify high-risk patients for early intervention.

## Key Findings
1. Glucose showed the strongest relationship with diabetes.
2. Higher BMI was associated with increased diabetes risk.
3. Older patients were more likely to have diabetes.
4. Family history contributed to diabetes occurrence.
5. Patients with both high BMI and high glucose represented the highest-risk group.

🛠 Tools & Libraries Used:

✅ Python
✅ Pandas
✅ NumPy
✅ Matplotlib
✅ Jupyter Notebook

## Skills Demonstrated:

• Data Cleaning & Preprocessing
• Exploratory Data Analysis (EDA)
• Data Visualization
• Statistical Analysis

## Recommendations
1. Increase diabetes screening for patients with elevated glucose.
2. Promote weight-management programs.
3. Focus preventive care on older patients.
4. Include family history in risk assessment protocols.
5. Monitor patients exhibiting multiple risk factors.
