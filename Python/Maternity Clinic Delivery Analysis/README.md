# Maternity Clinic Delivery Analysis

## Description
This Python project analyzes delivery data from a maternity clinic to track C-sections, 
normal deliveries, and complications. It helps identify trends
and insights to improve healthcare delivery and patient care.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn

## How to Run
1. Download the dataset `maternity_data.csv` (included in the repo)  
2. Open `delivery_analysis.py` in any Python IDE or Jupyter Notebook  
3. Run the script to generate tables, charts, and visual insights

## Key Insights
- **C-section rate:** 30% of total deliveries  
- **Peak delivery day:** Day 23  
- **Most common complications:** Pre-eclampsia and postpartum hemorrhage (PPH)  
- Visualizations clearly show trends in delivery types and complications.
