E-Commerce Sales Analysis | SQL & Power BI Project
##  Project Summary

This project demonstrates my ability to analyze business data
end-to-end using SQL and Power BI, transforming raw 
transactional data into actionable insights for decision-making.

Using a simulated e-commerce database, I designed a relational data model,
wrote SQL queries to extract meaningful metrics, and built an interactive
Power BI dashboard to answer real-world business questions 
around sales performance, product pricing, and revenue optimization.

##  Business Problem

E-commerce teams need quick answers to questions such as:

Which products drive the most revenue?

How does pricing impact order value?

Which orders qualify as high-value?

Where should pricing or sales focus be adjusted?

This project addresses those needs through 
structured analysis and intuitive visual reporting.

##  Data Model & Sources

The analysis is based on two relational tables:

# Products

Product ID

Product Name

 Category

Price

# Orders

Order ID

Product ID

Quantity

Total Price

A one-to-many relationship was created using product_id, 
ensuring accurate aggregation and filtering in Power BI.

##  Key Analytical Questions Answered

Total number of orders placed

Total revenue generated

Average product price

Highest-priced product

Highest-value order

Revenue and order volume by product

Identification of high-value orders using dynamic price thresholds

##  Dashboard Highlights

The Power BI dashboard includes:

# Executive KPIs

Total Orders Placed

Total Revenue

Average Product Price

# Interactive Filters

Product Category

Product Price

Order Value Threshold

# Core Visuals

Product catalog with pricing overview

Product price comparison bar chart

Order volume and revenue by product

High-value orders table driven by slicer logic

All visuals respond dynamically to slicer selections, enabling fast scenario analysis.

##  Key Metrics (DAX)

Total Orders – Count of order records

Total Revenue – Sum of order values

Average Product Price – Correctly calculated using product-level pricing

Care was taken to ensure proper aggregation, formatting,
and filter context, avoiding common reporting errors.

##  Insights & Business Value

High-priced products (e.g., electronics) contribute disproportionately to revenue.

Lower-priced products can still drive meaningful sales through higher order volumes.

Dynamic price filters help identify premium orders for targeted marketing or promotions.

The dashboard provides a clear foundation for pricing strategy and sales optimization decisions.
